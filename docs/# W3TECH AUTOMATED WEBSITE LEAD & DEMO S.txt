# W3TECH AUTOMATED WEBSITE LEAD & DEMO SAAS

## Full Local Python + SQLite Application

You are a senior Python engineer, automation engineer, UI/UX engineer and QA engineer.

Build a complete LOCAL-FIRST lead generation and website-sales automation application for my web-development business, W3Tech.

The purpose of the application is:

FIND BUSINESS LEADS → ANALYZE THEIR ONLINE PRESENCE → SCORE THEM → GENERATE A PERSONALIZED WEBSITE DEMO → GENERATE PERSONALIZED OUTREACH → TRACK EVERYTHING → CONVERT INTERESTED LEADS INTO WEBSITE CLIENTS.

The application must run completely on my Windows computer initially.

Do NOT build unnecessary cloud infrastructure.

==================================================

1. BUSINESS CONTEXT
   ==================================================

Business:
W3Tech

Website:
https://w3tech.co.in

Business service:
Website design and development.

Main sales strategy:

1. Find businesses.
2. Determine whether they have a website.
3. Analyze their existing website if available.
4. Identify opportunities:

   * no website
   * outdated website
   * poor mobile experience
   * slow website
   * weak CTA
   * poor design
   * missing WhatsApp/contact functionality
   * obvious technical problems
5. Score the lead.
6. Select an appropriate W3Tech website template.
7. Generate a personalized demo website.
8. Give the demo a unique URL/slug.
9. Generate a personalized outreach message.
10. Allow me to review it.
11. Send only through configured/approved communication channels.
12. Track opens, clicks, replies and status where technically/legalistically supported.
13. Convert interested leads into website projects.

IMPORTANT:

Do NOT design the application around mass unsolicited WhatsApp spam.

WhatsApp functionality must use an official/authorized Business API integration when enabled.

The application must support a MANUAL REVIEW mode by default.
